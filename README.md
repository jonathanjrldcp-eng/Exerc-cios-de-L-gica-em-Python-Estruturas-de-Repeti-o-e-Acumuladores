# Exerc-cios-de-L-gica-em-Python-Estruturas-de-Repeti-o-e-Acumuladores
Este repositório contém um script prático com quatro exercícios independentes que demonstram o uso de laços for, manipulação da função range(), formatação de saída (print) e lógica condicional.  O script pausa e limpa a tela do terminal entre cada exercício para proporcionar uma experiência interativa e organizada.
